# BGLM
Bayesian Generalized Linear Models (BGLM) is a project that implements uni-trait, multi-trait and multi-environment Bayesian regressions using different types of prior distributions like FIXED, BRR, BayesA, BL, and also RKHS regression. Different types of co-variance structures can be specified: Unstructured (UN), Diagonal (DIAG), Factor Analysis (FA), and Recursive (REC).
